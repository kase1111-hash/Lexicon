## Ask a question or report a bug

Use [GitHub issues](https://github.com/kase1111-hash/Lexicon/issues). Search
the open and closed issues first, then
[open a new one](https://github.com/kase1111-hash/Lexicon/issues/new/choose)
with the bug report or feature request template. For a bug, include the
command or request, its full output, the commit you run, and the `/health`
response or `lexicon stats` output.

Lexicon is maintained by volunteers; there is no guaranteed response time and
no commercial support.
